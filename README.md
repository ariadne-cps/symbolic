# Ariadne Symbolic

Ariadne Symbolic is the standalone symbolic-expression layer of Ariadne. It provides named variables and spaces, expressions, valuations, assignments, predicates and symbolic sets on top of Ariadne Kernel.

The repository depends on `ss/kernel` and `ss/configuration`, exposes `include/ariadne-symbolic.hpp`, builds `ariadne-symbolic`, and provides C++/Python tests and tutorials.
